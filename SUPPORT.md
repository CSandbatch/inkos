# Support

- Setup and usage questions: GitHub Discussions → Help.
- Reproducible defects: use the bug report issue form.
- Feature and genre-pack proposals: use the relevant proposal form.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public issue.

InkOS is alpha software maintained on a best-effort basis. Include the InkOS version, Node.js version, operating system, exact command, and redacted logs. Never attach API keys, `.env` files, manuscripts, or a production SQLite database to a public report.
