Start with [Getting started](/novelgraph/docs/getting-started/) to launch the local Studio. Mystery projects should continue with [Build a fair mystery](/novelgraph/docs/guides/mystery/), [Evidence and reader trust](/novelgraph/docs/guides/evidence-and-trust/), and the generated [fair-play rule reference](/novelgraph/docs/reference/fair-play-rules/).

NovelGraph keeps manuscripts, credentials, SQLite state, sealed solutions, and agent artifacts on the author's machine. The public demo uses immutable fixture data and never receives a real project.
