Start with [Getting started](/inkos/docs/getting-started/) to launch the local Studio. Mystery projects should continue with [Build a fair mystery](/inkos/docs/guides/mystery/), [Evidence and reader trust](/inkos/docs/guides/evidence-and-trust/), and the generated [fair-play rule reference](/inkos/docs/reference/fair-play-rules/).

InkOS keeps manuscripts, credentials, SQLite state, sealed solutions, and agent artifacts on the author's machine. The public demo uses immutable fixture data and never receives a real project.
