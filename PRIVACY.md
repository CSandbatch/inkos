# Privacy

NovelGraph is local-first. Manuscripts, prompts, model responses, graph state, credentials, project names, paths, and research snapshots are prohibited from telemetry and remain in the local workspace unless the author explicitly exports or transmits them.

The public demonstration uses bundled fixture data and does not call a model or persist a manuscript.

Optional diagnostics are off until enabled and may contain only a random installation identifier, NovelGraph version, operating-system family, Node.js version, command or workflow name, duration bucket, outcome category, and coarse error code. Implementations must expose the payload, provide a persistent off switch, reject unknown fields, document retention, and provide deletion instructions before collection is enabled.
